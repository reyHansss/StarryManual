巡逻区域决定 NPC 去哪里，连接决定按什么顺序去。这一篇说明四种区域的采样方式、区域上的公共设置，以及 NPC 在路线上选择下一个区域的完整规则。

## 四种区域

在 **Place Actors → StellaPatrol** 中可以放置四种区域：

| 区域                | 形状与大小                                                                  | 采样点                                    |
| ------------------- | --------------------------------------------------------------------------- | ----------------------------------------- |
| Stella Patrol Point | 单个位置                                                                    | 只有区域自身位置一个点                    |
| Stella Patrol Ring  | 圆形，`Radius` 默认 350 cm                                                  | 圆内按 `Distance Between Points` 排成方格 |
| Stella Patrol Box   | 矩形，基础大小 600 × 600 cm，用 Actor 的缩放调整大小                        | 矩形内按同样间隔排成方格                  |
| Stella Patrol Shape | 闭合样条围成的多边形；样条点少于 3 个时，自动生成半径 350 cm 的四点基础形状 | 落在多边形内部的方格点                    |

`Distance Between Points` 默认 150 cm，最小 10 cm。几点说明：

- **采样点在区域的水平面上**：方格铺在区域 Actor 自身的局部平面上，移动时目标点再投影到导航网格。把区域摆在地面附近即可。
- **样条只表示边界**：Shape 的样条围出一块区域，NPC 在区域内的采样点之间移动，不会沿样条连续行进。
- **只有 Box 使用缩放**：其他区域的 Actor 缩放会被重置为 1，大小由各自的属性决定。
- **区域可以随物体移动**：采样点以区域 Actor 的局部坐标保存，运行时移动或旋转区域，采样点随之移动。

<Note title="太小的 Shape 可能没有采样点">

圆形和矩形算不出采样点时，会退回区域中心一个点；Shape 没有这层兜底。没有采样点的区域不会登记到区域索引，也就不会被查询选中；把它设为 `First Zone` 时，第一次移动就会失败并停止巡逻。缩小点距或扩大样条即可。

</Note>

## 区域的公共设置

| 设置                                 | 分类      | 含义                                                                    |
| ------------------------------------ | --------- | ----------------------------------------------------------------------- |
| `Zone Tags`                          | Settings  | 区域标签，供巡逻组件的查询筛选                                          |
| `Weight`                             | Settings  | 被随机选中的相对权重，默认 1；0 表示不参与任何随机选择                  |
| `Next Patrol Zone`                   | Links     | 正向连接：从这里可以去的区域                                            |
| `Previous Patrol Zone`               | Links     | 反向连接，只读，由编辑器根据其他区域的正向连接维护                      |
| `Next Zone Wait Time`                | Links     | 停留时间，单位秒，默认 0；Point 没有这一项                              |
| `Navigation Actions`、`Zone Actions` | Actions   | 途中动作与到点动作，见[巡逻动作](/read/stellapatrol-movement#巡逻动作)  |
| `Debug Color`、`Debug Mesh Scale` 等 | Debugging | 编辑器显示，见[调试与排查](/read/stellapatrol-debugging#编辑器里的显示) |

区域的配置被所有 NPC 共用：每名 NPC 的前进方向、当前区域和动作实例都保存在自己的巡逻组件里。

## 把区域连成路线

- **添加连接**：在区域的 `Next Patrol Zone` 中添加后继区域，对方的 `Previous Patrol Zone` 会自动加上本区域。删除区域时，两侧的引用一起清理。
- **复制区域延长路线**：复制出的区域先清空自己的连接；如果离它最近的区域已经出现在别的区域的 `Next Patrol Zone` 中，就自动从那个最近区域连到新区域。
- **编辑器显示**：连接显示为一串方向箭头，默认沿导航路径排列。

### 怎样选下一个区域

停留时间到了以后，NPC 在下一次到点时按这个顺序决定去向：

1. **确定方向**：方向初始为正向。当前区域只有反向连接、没有正向连接（路线末端）时，方向变为反向；只有正向连接、没有反向连接（路线起点）时，方向变为正向；两种连接都有时保持原方向。
2. **按方向选连接**：在正向或反向连接中按目标区域的 `Weight` 随机选一个。失效的区域、没有采样点的区域和权重为 0 的区域不参与。
3. **没有可选的连接时查询**：从区域索引中挑选，规则见下一节，当前区域除外。
4. **仍然没有**：留在当前区域，继续在采样点之间漫游。

例如下面这条带岔路的路线：

<Diagram
  title="岔路按目标区域的权重选择（示例）"
  source={'flowchart LR\n  A(A：起点) --> B(B)\n  B --> C(C：Weight 2)\n  B --> D(D：Weight 1)'}
/>

- 从 A 到 B 之后，NPC 有 2/3 的机会去 C、1/3 的机会去 D。
- C 和 D 都是末端，停留结束后方向变为反向，回到 B。
- B 既有正向也有反向连接，于是保持反向，回到 A。
- A 是起点，方向重新变为正向，再去 B。

**环线**：A → B → C → A 这样首尾相接时，每个区域都同时有两种连接，方向一直保持正向，NPC 沿环线一直走下去。

## 第一次选区与没有路线的区域

开启巡逻时，组件先使用 `First Zone`。没有设置、区域已经失效或不在同一个世界时，按组件的 `Search Params` 查询区域索引；巡逻途中当前区域被删除，也会这样重新选区：

| 字段                | 含义                                                                                  |
| ------------------- | ------------------------------------------------------------------------------------- |
| `Tags`              | Gameplay Tag 查询，与区域的 `Zone Tags` 匹配；留空表示不限                            |
| `Max Distance`      | 查询半径，单位 cm，按 NPC 到区域内最近采样点的距离计算；0 表示不限                    |
| `Find Closest Zone` | 只在没有当前区域时生效：直接取距离最近的区域，不再按权重随机；权重为 0 的区域仍然排除 |

其余情况都按权重随机选择。路线中间没有可用连接时也走同样的查询，只是排除当前区域，并且不受 `Find Closest Zone` 影响。所以，**完全不连线的一组区域**也能用来巡逻：NPC 每次停留结束，就从附近符合标签和距离的区域中按权重随机挑一个。

区域在开始运行时登记到所在世界的区域索引，前提是已经有采样点；结束运行时注销。区域索引只存在于游戏和 PIE 世界。

## 停留时间

- **从选中区域开始计时**：`Next Zone Wait Time` 从选中这个区域的时刻算起，包括走过去的时间；路途比停留时间长时，到达后执行完到点动作就会离开。
- **停留期间在区域内漫游**：时间没到时，NPC 在本区域随机选一个采样点走过去；每到一个点，都会把区域的到点动作重新执行一遍。
- **到点动作不受停留时间打断**：时间在动作执行期间到期，也要等全部到点动作结束后才离开。

代码位置（插件 `Plugins/AI/StellaPatrol/Source/StellaPatrol`）：`StellaPatrolZone`（连接、权重与下一区域选择）、`StellaPatrolPoint`／`Ring`／`Box`／`Shape`（采样）、`StellaPatrolSubsystem`（区域索引与查询）、`StellaPatrolComponent`（停留与选区时机）。
