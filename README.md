# Starry手册

Starry 游戏项目的文档，面向项目使用者与开发者，记录技术架构、玩法系统与开发工具，提供功能配置、使用说明、扩展与排查。项目基于 UE 5.8，文档随项目开发持续补充。

本轮先整理 AstraAI、HaloDebug 和项目 Input 的详细章节；项目总览与架构页从整个工程说明角色、能力、战斗、世界玩法、玩家体验和开发支持等领域。

手册在自己的 Git 仓库管理，内容与站点资源独立。当前只在本地修改、验证和提交，不推送或发布。

## 本地运行

环境：Node.js 22.18+（推荐 24 LTS）、pnpm 11。本机使用 Node.js 24.19.0、pnpm 11.25.0。

```powershell
pnpm install
pnpm dev
```

访问 <http://127.0.0.1:3210>，右上角可以进入本地网页编辑器。开发服务绑定回环地址。

```powershell
pnpm format:check
pnpm check:content
pnpm build:pages --base-path /StarryManual
pnpm check:pages
pnpm preview:pages --port 3211
```

静态预览：<http://127.0.0.1:3211/StarryManual/>。`out/` 是忽略的构建产物，不提交。生产服务使用已构建内容，修改后需要重新构建；开发模式直接重新编译。

## 修改内容

文章位于 `content/articles/*.mdx`，本地文件和 Keystatic 网页编辑修改同一份内容。元信息只需标题、简介、分类和阅读顺序。文章沿用所属模块的稳定前缀；新模块在共享导航登记一次，未单独归组的文章进入项目系统，空分组不显示。现有分类用于文章类型和图谱着色。

正文 `/read/slug` 链接自动生成出链、反链和图谱。首页仅预览六个导览节点，完整图谱展示全站；局部图包含中心文章与正反向一跳邻居，支持跨分类关系。

笔记以任务、配置步骤、原理、约束和排查为结构。接口、字段、默认值与单位核对实际实现；需要自建的示例配置明确说明，不假装已提供资产。

## 图表与视觉约定

正文用共享 `Diagram` 输入 Mermaid 关系、流程、时序或状态。自动布局、四色主题、滚轮缩放、左键平移、键盘操作与全屏由共享组件提供，日常不手调坐标或单篇样式。

知识图谱展示阅读关联，不表示模块依赖；程序调用与对象关系由正文图表明确表达。完整图谱拖动关联节点会产生有限的弹性牵引，静止和不可见时停止计算，减少动态效果时关闭余动。缩小时文章标签随缩放渐隐，远景只保留节点与连线，放大后恢复。

用户已确认当前明亮、圆润、偏二次元的阅读设计。继续使用中性白底、暖粉主导、蓝色链接、清透图表和黄色星星向导；正文稳定、深灰文字、限制行宽，电脑利用导航与关联栏填满空间。

设计参考包括 [Emil Kowalski skills](https://github.com/emilkowalski/skills) 的动效节奏和 [garden-skills](https://github.com/ConardLi/garden-skills) 的共享 token、语义组件与可读性思路。参考研究不等于安装技能或引入运行依赖。重要约束保存在本仓库 `AGENTS.md`。

## 正文蓝图说明

介绍蓝图用法时，在文章中使用 `BlueprintViewer`，填写 `title` 与 `source`；网页编辑器提供同名含义的标题和多行节点文本字段。节点文本随文章保存与静态发布，打开正文直接渲染，支持多图、左键平移、滚轮缩放、触屏手势与原始文本查看。单组最多 200,000 字符。

`/blueprint` 仅用于写作时临时粘贴检查，文本刷新后移除，不列入主导航。共享画布只加载本地 blueprintUE 渲染器与手势脚本。

查看器不执行蓝图、不读 `.uasset`。复杂自定义节点、动画、材质、Niagara 与 PCG 的兼容性需按目标文本验证，不能把渲染器存在视作全部图种已验证。

## GitHub Pages 流程

独立仓库：<https://github.com/reyHansss/StarryManual>。已有站点：<https://reyhansss.github.io/StarryManual/>。

当前用户要求只本地修改，本轮内容没有推送，上述线上站点不会自动显示这些改动。在线可视化编辑与身份认证尚未配置，可在本地网页编辑，或直接通过 GitHub 编辑 MDX 后触发已配置的流程。

## 技术组成

Next.js 16 App Router、React 19、Fumadocs MDX/Core/UI、Keystatic、React Flow、d3-force、Mermaid 与本地 blueprintUE 渲染器。依赖版本由 package.json 与锁文件固定，页面可静态导出。

blueprintUE 固定版本、来源、许可与本地改动记录见 `THIRD_PARTY_NOTICES.md`；npm 依赖保留各自许可。普通内容修改运行相关检查，只有组件、模板变化或出现问题时增加对应验证。
