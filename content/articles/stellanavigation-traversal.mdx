手工放置连接适合少量的关键位置。地图里大量“可以跳过去”“可以攀上去”的地方，可以交给遍历分析自动寻找：在导航数据上配置分析器，烘焙平台或构建地面导航时，按代理尺寸和实际碰撞生成连接。生成的连接只让路径可以规划，跳跃、攀爬等动作仍由玩法执行。

## 配置分析器

选中关卡中的 `StellaNavigationData`，在 **Generation → Traversal Analysis** 中配置：

| 字段                    | 含义                                                             |
| ----------------------- | ---------------------------------------------------------------- |
| `Settings`              | 所有分析器共用的参数，距离单位为**米**                           |
| `Analyzers`             | 分析器数组，按顺序运行；数组为空表示关闭分析                     |
| `World Analysis Border` | 分析地面时每个 Tile 向外收集网格与碰撞的宽度，单位 cm，默认 2000 |

`Analyzers` 的每一项：

| 字段               | 含义                                                                                                              |
| ------------------ | ----------------------------------------------------------------------------------------------------------------- |
| `Analyzer`         | 从类型选择器中选一种分析器，展开后编辑它自己的尺寸；距离单位为**米**，角度单位为**弧度**                          |
| `Link Proxy Class` | 这一项生成的连接使用的共享执行代理；留空时只用于规划，见[共享执行代理](/read/stellanavigation-links#共享执行代理) |
| `Area Class`       | 这一项生成的全部连接使用的区域，默认 `NavArea_Default`，上行与下行不区分                                          |

可选的分析器有六种：**Jump（跳跃）**、**Climb Up（攀上）**、**Vault（矮墙翻越）**、**Duck Under（下穿）**、**Drop Down（下落）**、**Balcony Vault（阳台翻越）**。同一种分析器可以添加多项，分别配置不同的尺寸、执行代理和区域。

- **角色尺寸取自代理**：分析使用导航数据自己的代理半径与高度（从厘米换算为米），面板上没有另一套角色尺寸。
- **项目默认值**：项目设置的 **Stella Navigation → Traversal Analysis** 只提供新导航数据的默认配置，修改后重启编辑器生效；关卡中的导航数据可以各自覆盖。
- **不使用 UE 原生的自动跳跃采样**：Stella 导航数据隐藏并关闭了继承自 Recast 的自动跳跃链接配置，自动通道统一由遍历分析生成。

<Note title="会被拦下的配置">

配置无效时，烘焙失败并指出是数组中的哪一项、违反了哪条约束，旧的资产和已登记的导航保持不变。常见的两条：

- **Vault**：`MaxUpwardTravelDistance` 必须小于 `MinWallHeight`，默认分别为 0.4 米和 0.5 米；
- **Balcony Vault**：`MaxWallHeight` 必须小于代理高度。例如高 144 cm 的代理不能使用 1.5 米的最大墙高，要改成 1.3 米这样的值。

</Note>

## 结果保存在哪里

| 分析范围               | 什么时候运行                     | 结果保存在                                                                             |
| ---------------------- | -------------------------------- | -------------------------------------------------------------------------------------- |
| 同一个平台资产内部     | 烘焙或重新烘焙局部导航资产时     | 局部导航资产，与网格一起保存                                                           |
| 固定地面               | 编辑器中构建导航完成后自动运行   | 普通地图保存在导航数据中；World Partition 地图保存在原生导航数据块中，随 Tile 流送装卸 |
| 单个平台与固定地面之间 | 手动运行，见下文“平台与地面之间” | 平台 Actor 上的遍历组件，随地图保存                                                    |

保存的结果在运行时直接装配，不需要在 BeginPlay 里再分析一次。修改了分析器配置、或者 UE 重新生成了基础网格后，要重新烘焙资产或重新构建导航。

## 限定自动通道的范围

**地面**：在关卡中放置 **Stella Navigation Analysis Volume**，用它的 Box 调整位置、旋转和大小；多个启用的盒子取并集。

- **只限制起点**：起点所在的可走边与盒子相交就保留整条候选，终点可以在盒子外面；盒子不会裁剪通道本身。
- **没有盒子就不生成**：地图里没有启用的分析范围时，不生成新的地面自动连接，手工连接不受影响。
- **只在编辑器使用**：这个 Volume 不参与碰撞和导航几何，打包地图时被剔除；它也不随 World Partition 流送，保证构建时能读到全部范围。

**平台资产**：在局部导航资产的 `Analysis Ranges` 中添加局部盒子，规则相同：数组为空时，资产内部不生成自动连接。关卡中的 Analysis Volume 不会写进可复用的资产。

修改范围后，重新构建导航会刷新全部地面自动连接；只想更新一部分时，用下面的局部重建。

## 局部重建地面

选中提供范围的 Actor 或 Volume，在视口中右键，选择 **导航 → StellaNavigation → 重建所选范围的地面导航与 Link**：

- **重建什么**：与所选包围盒相交的地面 Tile（同一列的全部高度层），以及依赖这些 Tile 的自动连接；范围外的 Tile 和其余已保存的连接保留。
- **前提**：先完成过一次普通的导航构建；导航正在生成或暂停时不能使用。
- **World Partition**：先加载所选区域及周边分析所需的区块，工具发现有未加载的 Actor 时会拒绝；完成后按正常流程保存受影响的区块。

## 平台与地面之间

平台资产内部的通道和地面上的通道互不相干；平台边缘到地面之间的跳跃、下落等通道需要单独分析：

1. 先烘焙平台的局部导航，并构建好地面导航。
2. 单选平台，在视口中右键，选择 **导航 → StellaNavigation → 分析平台与固定世界的遍历通道**。平台有多个表面或关卡有多种代理时，会弹窗让你选择“表面 → 导航数据（代理名）”。
3. 预期结果：平台上添加（或复用）一个遍历组件，`Source Surface` 与 `Navigation Data` 指向所选的组合，连接保存在组件里，随地图保存。

- **只分析平台和固定地面**：不包括其他平台。平台与平台之间的业务连接用手工 NavLink。
- **平台移动时不重新分析**：连接两端分别跟随平台和地面，平台开走后通道仍然存在，路径可能仍会经过它；能否真的通过，由执行代理在入口检查。
- **清除**：运行时调用遍历组件的 `Clear Links`，删除这个组件的全部连接和保存的结果，之后只有重新分析才会再生成。
- **几何改变**：连接引用的网格发生改变时，这组连接被撤下并提示需要重新分析。

## 动作由谁执行

自动生成的连接只说明“这里可以规划过去”。跳跃输入、攀爬动画、动作许可、完成与取消都由玩法实现：给分析器配置 `Link Proxy Class`，在执行代理的入口回调中根据进入的角色和当前碰撞计算抓点、起跳与动画对齐，完成后调用 `Finish Custom Link`。没有配置执行代理时，角色到达后按普通移动继续走，不会自动跳跃或攀爬。

代码位置（插件 `Plugins/AI/StellaNavigation/Source`）：`StellaNavigation/Public/Traversal/StellaNavigationTraversalAnalysisConfig.h`（配置）、`Traversal/StellaNavigation*Traversal.h`（六种分析器）、`Traversal/StellaNavigationAnalysisVolume.h`（分析范围）、`Traversal/StellaNavigationTraversalComponent.h`（平台对外通道）、`StellaNavigationEditor/Private/StellaNavigationEditorTools.cpp`（右键菜单）。
