## 区域做两件事

`UStellaUtilityAIBehaviorZoneComponent` 挂在关卡里的普通 Actor 上，不需要专用的区域 Actor。它做两件相关的事：

- **按分配关系应用 Modifier**：分配给这个区域的 NPC，会被应用区域配置的 Modifier，例如“守卫这片营地时使用警戒行为”。
- **提供区域几何**：判断位置是否在区内、离区域最近的点有多远，并为分配的 NPC 生成“回到区域”的机会。

区域不是触发器：NPC 走进去并不会自动被分配。分配关系由关卡初始配置或玩法代码显式指定。

## 配置一个区域

1. 在 Actor 上添加 Box 或 Sphere 组件作为区域形状，再添加 `UStellaUtilityAIBehaviorZoneComponent`。
2. 在 `Shape` 中引用这个形状组件；留空时取 Actor 的根形状。组件不会修改形状的碰撞设置。
3. 在 `ModifierApplications` 中添加应用条目：

| 字段                    | 含义                                                                  |
| ----------------------- | --------------------------------------------------------------------- |
| `BehaviorModifierClass` | 要应用的 Modifier 类                                                  |
| `ModApplianceType`      | 应用方式，目前只有 `ApplyWhileAssigned`：分配期间一直生效             |
| `ViableAiAgentQuery`    | 对 NPC 的 **Pawn** 标签的查询，决定这条应用对谁生效；空查询表示不限制 |

4. 指定分配关系：
   - 关卡中的初始分配：在 `AssignedAgents` 中填写，只能在关卡实例上编辑；
   - 运行时：调用 `Assign`／`Unassign`。
5. 运行后，在 **AI → Modifiers** 面板确认 NPC 身上出现了对应的应用。

## 分配的时机与寿命

- **先登记、后应用**：NPC 的 AI 还没就绪时，也可以先登记分配，等就绪后再应用。`Assign` 返回成功不代表那一刻已经完成应用。它要求区域已经注册：区域组件在 BeginPlay 时（处于激活状态才会）注册，开始游戏后再 `Activate` 也会注册，`Deactivate` 时注销。
- **刷新资格**：NPC 的标签变化后，资格不会自动重新判断，需要显式调用 `RefreshEligibility`。仍然适用的条目保留原来的应用句柄，不会先删后加而重复触发事件。
- **分配随会话结束**：NPC 的 StellaUtilityAI 会话结束或 Pawn 结束游戏时，它的分配整条删除，下次会话不会自动恢复。

## 编辑器里批量分配

区域组件的 **Assign All Overlapping Editor Agents** 按钮，按已加载 Pawn 的世界包围盒收集当前与区域重叠的角色，写入 `AssignedAgents`，并支持撤销。

**限制：**

- 只在编辑器世界中生效；
- 只收集 `Auto Possess AI` 不为 Disabled 的 Pawn；
- 它是配置初始分配的便捷操作，不是运行时持续监听进入区域的角色。

## 几何查询与回区机会

| 接口                                                               | 作用                                                             |
| ------------------------------------------------------------------ | ---------------------------------------------------------------- |
| `ContainsLocation(Location)`                                       | 判断位置是否在区域内                                             |
| `GetClosestLocation(Location, Closest, Distance)`                  | 取区域上离该位置最近的点，以及距离（厘米）                       |
| `UStellaUtilityAIZoneSubsystem::GetAssignedZones(Pawn)`            | 取得 NPC 当前的全部有效分配区域                                  |
| `UStellaUtilityAIZoneSubsystem::IsLocationAllowed(Pawn, Location)` | 位置在 NPC 的**所有**有效分配区域内时返回 true；没有分配时不限制 |

最近的几何点不保证 NavMesh 可达，也不保证角色能站立。

`UStellaUtilityAIObjectiveGenerator_ReturnToZone` 为在区外的分配角色生成回区机会，覆盖所有有效的分配区域；角色在区内时没有这项机会。选择回哪个区域、怎样投影到导航网格、怎样移动以及失败后怎么办，都由具体的 Behavior 与 Logic 决定。

只挂一个 Zone 不会让 NPC 被自动传送或被限制移动。需要“软束缚”或“硬束缚”时，由具体行为的条件、评分和持续约束来表达。

行为层的覆盖规则见[组合与覆盖](/read/stellautilityai-composition)，机会的写入规则见 [Objective 与生成器](/read/stellautilityai-objectives)。

代码位置（插件 `Source/StellaUtilityAI`）：`Zones/StellaUtilityAIBehaviorZoneComponent`、`Zones/StellaUtilityAIZoneSubsystem`、`Zones/StellaUtilityAIObjective_ReturnToZone`。
