## 一句话介绍

Starry 是一个 Unreal Engine 5.8 游戏项目，运行在自维护的源码引擎 **StarryUE** 上。项目以 C++ 框架为主体：

- **玩法装配**：采用 Lyra 风格的 Experience。
- **角色**：使用 Mover 移动，动画沿用 GASP（Game Animation Sample）的方案。
- **技能与战斗**：基于 GAS，融合了 Ninja 系列插件的能力。
- **AI**：由项目自研的 StellaAI 决策、StellaNavigation 导航。
- **生态**：按《怪物猎人：荒野》的规则复刻怪物与生物的日常生态。

## 游戏方向

以下是已经确定的方向。它们决定了框架的设计，但大部分联机能力还没有实现：

- **探索与存档**：探索可以离线进行，非付费内容和进度走本地存档。
- **网络部署**：按玩法选择。PvP 这类玩法可以由服务器权威执行；本地存档不等于客户端拥有战斗权威。
- **公共大厅**：可以看到大量陌生玩家。
- **合作探索**：朋友进入同一环境后可以连续自由探索，承接任务时可以有过渡。

具体的部署方案和尚待决定的规则见[网络与权威](/read/arch-network)。

## 现在有什么

| 范围      | 已有能力                                                                                              |
| --------- | ----------------------------------------------------------------------------------------------------- |
| 框架      | 四类角色（玩家、AI、NPC、怪物）、Mover 移动、GAS 能力与战斗、输入、装备、背包、阵营、相机、设置与界面 |
| 玩法      | 生态运行框架、怪物状态、任务、前端流程                                                                |
| AI 与导航 | StellaAI 组合决策及 BT／StateTree／HTN 后端、StellaNavigation、StellaPatrol 巡逻                      |
| 工具      | StellaDebug 调试面板、netImgui 远程查看、模块化编译工具 Starry UE Build                               |

目前**还没有**正式关卡（`Content/Maps` 为空），游戏流程尚未定稿，玩家进度的本地存档也还没有实现。可以运行的是示例地图与各系统的测试地图，见[第一次运行](/read/start-first-run)。

## 这本手册怎样用

- **找内容**：左侧用模块菜单切换系统，按 `Ctrl K` 全文搜索标题、概念和 API 名称。
- **看图**：正文图表可以滚轮缩放、拖动和全屏查看；部分时序图可以“逐步播放”，按消息顺序逐条看。
- **交互演示**：带“交互演示”标签的卡片可以直接操作，计算规则与项目源码一致。
- **关系图谱**：根据文章之间的链接生成，表示“可以一起读”，不表示代码依赖。

目前已经写成专题的模块有 StellaAI、StellaDebug、Input、Async Message 与 AsyncMixin。角色与移动、能力与战斗、导航、生态等系统暂时只在架构篇中概述，专题会陆续补齐。

文中的约定：

- 标为“示例”的资产名称需要你自己创建，项目里不一定存在。
- 标为“规划”的内容尚未实现。
- 每篇末尾的“代码位置”给出阅读源码的起点。
