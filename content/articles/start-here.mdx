## Starry 是什么

Starry 是基于 Unreal Engine 5.8 开发的游戏项目，工程包括可复用的基础框架、具体玩法系统和开发工具。Starry手册是整个项目面向使用者与开发者的文档，记录系统设计、功能配置、使用方法、扩展与排查。

| 项目领域       | 主要内容                                            |
| -------------- | --------------------------------------------------- |
| 工程与玩法装配 | GameMode、Experience、GameFeature、角色配置与初始化 |
| 角色与动作     | 角色、Mover 移动、动画、相机、技能与战斗            |
| 世界与玩法     | AI、生态、任务、交互、装备与背包、阵营              |
| 玩家体验       | 输入、界面、玩家设置、音频与反馈                    |
| 开发支持       | 调试面板、日志、编辑器工具与测试                    |

先读 [Starry 技术架构](/read/architecture)，了解这些能力在工程中的位置；需要完成具体操作时，再进入对应系统的使用章节。文档随项目开发逐步补充。

每章末尾给出实现入口，方便在工程中定位类型。操作路线中的示例资产名称需要自己创建；正文会区分当前实现、操作示例与尚未接完的能力，不把浏览器演示当成 UE 运行验证。

## 用目录查找，用图谱探索

左侧导航按模块组织，右侧目录定位当前页的小节。按 `Ctrl K` 搜索标题、概念或正文中的 API 名称。

知识图谱根据文章里的实际阅读链接自动生成。选择一个节点后可以打开文章，或进入以它为中心的局部图，再沿相连页面继续阅读。图谱的关联表示“这些文章可以一起读”，程序依赖和执行顺序由正文图表说明。

正文图表可以滚轮缩放、左键平移、适应画布或全屏查看。较长的流程先看完整图，再放大读分支，不需要把正文整页缩小。

## 查看真实蓝图节点

介绍蓝图用法的文章可以直接嵌入 UE 节点图，配合文字阅读执行连线、数据连接与参数。节点文本随文章保存，打开正文即可显示，支持平移与缩放。编写方式见[在文档中说明蓝图用法](/read/blueprint-nodes)。

## 自己修改内容

本地文章文件与网页编辑器修改同一份内容。日常只写正文、关系和必要图表，不为每一篇笔记重新做版式。具体操作与可复用模板见[维护这本手册](/read/writing)。
