## 它是什么

StellaDebug 是项目自维护的游戏内调试工具，提供：

- **调试窗口与菜单**：基于 Dear ImGui；
- **属性检查器**：查看和修改反射属性；
- **场景绘制**：点、线、形状、碰撞、曲线与指标；
- **远程显示**：把面板显示到桌面程序（netImgui）。

插件提供通用能力，项目在 `UStarryDebugSubsystem` 中注册自己需要的窗口：引擎通用工具、AI 面板和输入调试。各领域状态的含义和排查步骤写在所属模块中，这里只讲工具本身怎么用。

## 从 F1 开始

在非 Shipping 构建的 PIE 或游戏中，按 **F1** 切换调试输入：鼠标和键盘交给调试面板，从顶部菜单打开需要的窗口。检查完再按 F1 回到游戏操作。

| 快捷键 | 作用                             |
| ------ | -------------------------------- |
| F1     | 切换调试输入                     |
| F2～F4 | 载入第 1～3 套窗口布局           |
| F5     | 切换拾取模式（在视口中选 Actor） |

快捷键都可以重新绑定。默认会停用与它们冲突的 UE 调试按键。

## 菜单里有什么

| 菜单                 | 窗口                                                                                                                                                                                                                                |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Engine → Actor       | Inspector（属性）、Transform（位置旋转缩放）、Skeleton（骨架）、Cheats                                                                                                                                                              |
| Engine → Scene       | Collision Tester、Collision Viewer、Levels、Spawns                                                                                                                                                                                  |
| Engine → Diagnostics | Log Categories、Output Log、Notifications、Plots、Metrics                                                                                                                                                                           |
| Engine → Runtime     | Build Info、Debug Settings、Net Emulation、Scalability                                                                                                                                                                              |
| Engine → Debug Tools | ImGui、Slate、Command Bindings、Net ImGui                                                                                                                                                                                           |
| AI                   | Agents、StellaBehavior、Objectives、Modifiers、BehaviorTree、StateTree、HTN、Blackboard，见 [StellaUtilityAI 调试](/read/stellautilityai-debugging)；Coordination，见 [StellaCoordination 调试](/read/stellacoordination-debugging) |
| Input                | Gamepad、Actions，见 [Input 调试](/read/input-troubleshooting)                                                                                                                                                                      |
| Window               | Close All Windows、Layouts（重置布局，载入或保存布局 1～4）、Settings、Spacing 1～4                                                                                                                                                 |

**菜单栏右侧的小部件**：Selection（当前选择）、Time Scale（时间倍率）、Stats、Console，都显示在菜单栏右侧，可以在 **Window → Settings → Widgets** 中调整显示与顺序。插件自带的 Audio 窗口，项目没有注册。

## 选择对象与当前世界

**选择**：选择决定 Inspector、Transform 等工具操作哪个 Actor。

- 进入拾取模式（F5，或执行 `StellaDebug.ToggleSelectionMode`）后，在游戏视口中左键选择、右键取消。
- 拖动 Gizmo 需要游戏视口中的调试输入已经打开。

**Cheats**

- 默认作用于选中的 Actor；按住 `Ctrl` 点击时改为作用于本地控制的 Pawn。
- 控制台形式为 `StellaDebug.Cheat <CheatName> [-Controlled]`。
- 标记为 Persistent 的作弊会在下次运行时自动重新应用。
- Cheats 窗口的条目来自数据资产中的 `CheatCategories`，项目 Content 中目前还没有这个资产，所以默认是空的。

**操作只发生在当前进程与世界**：面板里的操作不会自动变成服务器 RPC，玩法权限与同步仍由对应领域处理。多人 PIE 中，先确认正在操作的是哪个世界。

## 控制台命令

| 命令                                           | 作用                                                 |
| ---------------------------------------------- | ---------------------------------------------------- |
| `StellaDebug.ToggleInput`                      | 切换调试输入（同 F1）                                |
| `StellaDebug.DisableInput`                     | 关闭调试输入                                         |
| `StellaDebug.ToggleSelectionMode`              | 切换拾取模式（同 F5）                                |
| `StellaDebug.LoadLayout <n>`／`SaveLayout <n>` | 载入或保存第 n 套布局                                |
| `StellaDebug.ResetLayout`                      | 重置窗口布局                                         |
| `StellaDebug.Cheat <CheatName> [-Controlled]`  | 执行作弊                                             |
| `StellaDebug.NetImgui.*`                       | 远程连接相关，见[远程面板](/read/stelladebug-remote) |

## 插件的模块分工

| 模块                | 职责                                   |
| ------------------- | -------------------------------------- |
| `StellaDebug`       | WorldSubsystem、窗口、菜单、布局与配置 |
| `StellaDebugCommon` | 公共接口与构建宏                       |
| `StellaDebugImgui`  | ImGui、输入、Slate 与 netImgui 接入    |
| `StellaDebugPaint`  | 本进程的场景绘制、Gizmo、曲线与指标    |
| `StellaDebugEngine` | 通用引擎工具窗口与反射属性检查器       |
| `StellaDebugInput`  | Gamepad 与 Actions 输入调试            |

宏 `ENABLE_STELLADEBUG` 在非 Shipping 构建中为 1。面板和工具代码按这个宏编译；部分运行时反射类型在 Shipping 中仍然存在，以便资产能正常加载，所以不能把它理解为整个插件在 Shipping 中完全消失。插件描述符默认禁用，`Starry.uproject` 显式启用了它。

## 看不到面板时

1. 确认不是 Shipping 构建，并且插件已启用。
2. 确认 F1 的调试输入已打开，窗口可见，当前世界正确。
3. 中文显示成方块时，检查非 Shipping 的字体文件是否已部署：字体按普通文件读取，只 Cook 进 Pak 不够。

把面板放到独立窗口显示，见[远程面板](/read/stelladebug-remote)；新增窗口与绘制，见[扩展开发](/read/stelladebug-extension)。

代码位置：插件 `Plugins/Toolkit/StellaDebug`；项目窗口注册 `Source/StarryGame/Framework/Development/StarryDebugSubsystem`。
