## 接口与准备

C++ 直接使用 `UAsyncMessageWorldSubsystem` 提供的原生系统：`BindListener` 监听、`QueueMessageForBroadcast` 发送、`UnbindListener` 解绑。它们与[蓝图节点](/read/asyncmessage-blueprints)共用当前 World 的消息系统，不需要先创建蓝图任务。

下面使用项目已注册的 `Starry.Damage.Message` 和已有 `FStarryVerbMessage`。`UMessageExampleComponent` 是供自己创建的文档示例组件，放在 `StarryGame` 模块中；工程没有预置这个类型。示例只发布与观察通知，不执行扣血或网络转发。

`StarryGame` 已具备依赖。放入其他模块时，确认 `Build.cs` 包含 `Core`、`CoreUObject`、`Engine`、`GameplayTags` 和 `AsyncMessageSystem`；公共头文件暴露消息系统类型时，相应依赖放入公开依赖列表。

| 操作         | 原生接口                                                          | 需要保存或传入的内容                 |
| ------------ | ----------------------------------------------------------------- | ------------------------------------ |
| 取得当前系统 | `GetSharedMessageSystem<FAsyncGameplayMessageSystem>(GetWorld())` | 同一个 World                         |
| 监听         | `BindListener`                                                    | 消息 Id、弱对象、成员回调、接收阶段  |
| 读取         | `Message.GetPayloadView().GetPtr<const T>()`                      | 与消息约定一致的结构体类型           |
| 发送         | `QueueMessageForBroadcast`                                        | 消息 Id、`FConstStructView` 载荷视图 |
| 解绑         | `UnbindListener`                                                  | 登记时的系统和它返回的句柄           |

## 声明组件与监听记录

`MessageExampleComponent.h` 保存这次监听的系统弱引用与句柄，避免组件结束时从另一个 World 解绑。它们是原生 C++ 记录，不需要用 `UPROPERTY` 保活 World 或消息系统。

```cpp
#pragma once

#include "CoreMinimal.h"
#include "AsyncMessageHandle.h"
#include "Components/ActorComponent.h"

#include "MessageExampleComponent.generated.h"

class FAsyncGameplayMessageSystem;
struct FAsyncMessage;

/** 观察所属 Actor 的伤害通知，并演示默认 World 范围的收发与清理。 */
UCLASS(ClassGroup=(Custom), meta=(BlueprintSpawnableComponent))
class STARRYGAME_API UMessageExampleComponent : public UActorComponent
{
	GENERATED_BODY()

public:
	/** 开始监听；已有监听先停止，返回本次是否取得有效句柄。 */
	bool StartListening();

	/** 发布测试通知；Magnitude 为通知数值，返回是否加入相关接收队列。 */
	bool SendDamageNotification(double Magnitude);

	/** 停止本组件拥有的监听并清空记录，可重复调用。 */
	void StopListening();

protected:
	// UActorComponent interface
	virtual void BeginPlay() override;
	virtual void EndPlay(const EEndPlayReason::Type EndPlayReason) override;
	//~ End of UActorComponent interface

private:
	/** 在游戏线程核对载荷类型，只处理 Target 为所属 Actor 的通知。 */
	void HandleDamage(const FAsyncMessage& Message);

	/** 指向登记时的系统，不延长 World 消息系统寿命。 */
	TWeakPtr<FAsyncGameplayMessageSystem> BoundSystem;

	/** 只用于撤销本组件建立的这一份监听。 */
	FAsyncMessageHandle DamageHandle;
};
```

以下实现放在同名 `MessageExampleComponent.cpp`，先包含这些头文件，再加入后面的函数：

```cpp
#include "MessageExampleComponent.h"

#include "AsyncMessage.h"
#include "AsyncMessageBindingOptions.h"
#include "AsyncMessageWorldSubsystem.h"
#include "Framework/Messages/StarryVerbMessage.h"
#include "GameFramework/Actor.h"
#include "GameplayTagContainer.h"
#include "StructUtils/StructView.h"
```

## 登记监听并接收

先取得当前 World 的系统，指定消息 Id 和成员回调，并保存 `BindListener` 返回的句柄。`MakeWeakObjectPtr(this)` 使用引擎提供的 UObject 弱绑定，不以裸 `this` 捕获跨越对象寿命。

```cpp
bool UMessageExampleComponent::StartListening()
{
	StopListening();

	const auto System =
		UAsyncMessageWorldSubsystem::GetSharedMessageSystem<FAsyncGameplayMessageSystem>(GetWorld());
	if (!System)
	{
		return false;
	}

	const FAsyncMessageId MessageId(
		FGameplayTag::RequestGameplayTag(TEXT("Starry.Damage.Message")));
	BoundSystem = System;
	DamageHandle = System->BindListener(
		MessageId,
		MakeWeakObjectPtr(this),
		&UMessageExampleComponent::HandleDamage,
		FAsyncMessageBindingOptions(TG_PostUpdateWork));
	return DamageHandle.IsValid();
}

void UMessageExampleComponent::HandleDamage(const FAsyncMessage& Message)
{
	const auto* Payload = Message.GetPayloadView().GetPtr<const FStarryVerbMessage>();
	if (!Payload || Payload->Target != GetOwner())
	{
		return;
	}

	UE_LOG(LogTemp, Display, TEXT("%s 收到伤害通知：%g"),
		*GetNameSafe(GetOwner()), Payload->Magnitude);
}
```

这里显式选择游戏线程的 `TG_PostUpdateWork`，便于安全访问 Actor 和表现数据。回调先检查载荷类型，再筛选自己的 `Target`；默认 Endpoint 会接收同一 World 的相应消息，不能只因标签正确就更新所有角色。

`GetPtr` 返回的指针只在当前消息回调内使用，不跨回调保存。需要稍后使用时复制必要字段；UObject 字段不会深复制。若改为监听父标签，先检查 `Message.GetMessageSourceId()`，不同子消息可能使用不同载荷。

## 发送结构体载荷

发送方构造业务结构体，用 `FConstStructView::Make(Payload)` 传给系统即可，C++ 不需要先调用蓝图的 `Make Instanced Struct`。系统会在入队过程中复制结构体，因此这里的局部变量可以在函数返回后销毁。

```cpp
bool UMessageExampleComponent::SendDamageNotification(double Magnitude)
{
	const auto System =
		UAsyncMessageWorldSubsystem::GetSharedMessageSystem<FAsyncGameplayMessageSystem>(GetWorld());
	if (!System)
	{
		return false;
	}

	FStarryVerbMessage Payload;
	Payload.Verb = FGameplayTag::RequestGameplayTag(TEXT("Starry.Damage.Message"));
	Payload.Instigator = GetOwner();
	Payload.Target = GetOwner();
	Payload.Magnitude = Magnitude;

	return System->QueueMessageForBroadcast(
		FAsyncMessageId(Payload.Verb),
		FConstStructView::Make(Payload));
}
```

这段发送不依赖发送方也登记监听；取得当前 World 的系统后，其他组件同样可以直接入队。此处为了让示例自身观察到消息，把 `Target` 设为所属 Actor。

返回 `true` 只说明进入了相关接收队列，不能代表自己的回调已经处理或网络传递成功。监听必须先启动；没有相关监听时通常返回 `false`。正式伤害处理已经发送通知，不再额外调用本测试方法发布一份。

## 解绑并接入宿主生命周期

使用**原系统与原句柄**配对解绑，再清空两份记录。解绑不会自动清空调用方保存的句柄；只重置句柄也不会撤销系统中的监听。

```cpp
void UMessageExampleComponent::StopListening()
{
	if (const auto System = BoundSystem.Pin())
	{
		System->UnbindListener(DamageHandle);
	}
	DamageHandle = FAsyncMessageHandle::Invalid;
	BoundSystem.Reset();
}

void UMessageExampleComponent::BeginPlay()
{
	Super::BeginPlay();
	StartListening();
}

void UMessageExampleComponent::EndPlay(const EEndPlayReason::Type EndPlayReason)
{
	StopListening();
	Super::EndPlay(EndPlayReason);
}
```

可反复开关的功能还应在每次关闭时调用 `StopListening`，重新打开时调用 `StartListening`，不必等到对象销毁。弱对象绑定避免调用已失效对象，但不能代替“对象仍活着、功能已经关闭”时的退订。

解绑请求在队列预处理阶段移除监听，不是跨线程等待屏障，不能撤回已经开始运行的回调。本例保持在游戏线程；显式使用后台线程时，需要按自己的任务生命周期协调退出，详细约束见[标签、时机与生命周期](/read/asyncmessage-routing)。

## 核对收发与清理

将自建组件放到测试 Actor，进入 PIE 后由明确的测试入口调用 `SendDamageNotification(25.0)`，预期在接收阶段输出一次数值。再调用 `StopListening()` 后发送，自己的回调不再输出；重新 `StartListening()` 后应只收到一份，重复开始不能叠加监听。

以上代码已按本机 UE 5.8 的公开接口核对，本轮未将示例加入工程或执行编译、PIE。现有项目消息、状态复制与显式 RPC 的实际接入见[项目消息与排查](/read/asyncmessage-project)。

实现入口：引擎插件公开的 `AsyncMessageSystemBase.h`、`AsyncGameplayMessageSystem.h`、`AsyncMessageWorldSubsystem.h`、`AsyncMessage.h`、`AsyncMessageHandle.h` 与 `AsyncMessageBindingOptions.h`。
