# 点阵输入与关系图谱更新记录

## 2026-10-26：修复间歇性扰动减弱，减少图谱重复更新

用户反馈知识图谱响应偏慢，首页点阵在正常运行一段时间后会突然几乎不响应鼠标，稍后恢复。

### 已复现的问题

`components/particle-effects.tsx` 原先在每条指针事件里计算速度，但把间隔下限固定为 16 毫秒。事件频率高于绘制频率时，事件间位移变小，分母却不会相应减小；随后到达的同坐标事件还会把速度直接覆盖为零。

在真实输入监听与 RAF 的隔离测试中，同样以 1000 CSS 像素／秒移动，60 次／秒输入在绘制前衰减后约为 890，960 次／秒约为 58；每帧末尾补一条同坐标事件时，读数变为零。它能复现“仍在划动但扰动很弱”的输入失效，不据此认定用户遇到的所有间歇卡顿都来自同一原因。

### 实现

- 指针事件保存最新坐标，绘制帧按两帧之间的实际位移与时间计算速度；同帧的同坐标事件不会抹掉此前位移。
- 保留速度上限、停手衰减、原有粒子展开与慢回位算法、触摸短脉冲、全局暂停、减少动态效果、离屏／后台停帧和卸载清理。
- `components/knowledge-graph.tsx` 仅在选择或操作入口变化时更新节点数据；位置帧复用连线与回调，并按节点数据记忆化内容。位置由 React Flow 外层处理，缩放仍通过原有订阅更新圆点与标题。
- `components/use-graph-motion.ts` 保留没有位移的节点引用，保持拖动节点直接跟随输入；不改变弹力、布局和有限余动规则。

### 验证

- `pnpm test:particles`：5 项通过，覆盖 60／120／960 次／秒输入、同坐标事件、12 轮快慢划动与停帧再唤醒、触摸、后台／离屏恢复、暂停及清理。旧源码执行相同用例时 3 项失败，修复后全部通过。
- `pnpm test:graph`：12 项通过，包含布局、局部关系、缩放尺寸、牵引和有限余动，以及位置更新复用引用、选择不重置拖动坐标。
- 对三节点执行 60 次位置更新的隔离计数：节点数据重建从 180 次降至 0，连线数组和手势回调各从 60 次降至 0。这里只计数组与对象引用变化，不是浏览器实际渲染次数或 FPS 测量。
- `pnpm typecheck` 与 `/StarryManual` 静态构建通过；`pnpm check:pages` 检查 40 个 HTML、32 篇文章和 3379 处本地资源／链接，无失效引用。
- 本地静态页面在约 972 × 742 CSS 像素视口中复查了点阵拨动、暂停与恢复，模块图拖动牵引、滚轮缩放、选择后位置保持，以及全部文章和局部图入口；缩放后标题正常恢复。
- 新增粒子测试接入现有 Pages 工作流，沿用本地修改与验证的范围，未推送或发布。

### 验证边界

输入测试替换了 Canvas 绘制以隔离事件采样，组件测试替换了 React 调度以检查交给 React Flow 的数据；实际绘制和手势另由浏览器复查。未对用户鼠标的真实报告率、长期运行或不同 GPU／浏览器做性能采样，不能把引用计数直接换算为帧率收益。

构建仍有 Fumadocs 搜索样式 `::highlight` 的两条优化器警告，测试仍有 Node 对现有 TypeScript 模块类型声明的提示，均未导致本次检查失败。

## 2026-10-26：按 Obsidian 参考调整图谱临时强调

用户核对 Obsidian 后反馈：节点不应常驻选中，字号应更小，鼠标停留或拖动时高亮节点与连线，其余内容变灰、变淡。本轮在用户确认后修改完整图谱，紧凑卡片保留原有选择与导航。

### 实现与直接发现的问题

- 详情选择与临时强调分开：完整图不再默认选择首个节点，详情面板初始显示范围、节点与关联数量。点击节点查看详情，移开后图谱恢复全貌；空白点击恢复概览。文章与子图操作统一放在详情面板，删除节点下方的常驻操作按钮。
- 悬停或键盘聚焦只突出当前节点、一跳邻居及当前节点的直接连线；邻居之间的连线不跟着高亮。直接连线沿用当前节点的模块色，无关节点变灰并降至 0.24 透明度，无关连线降至 0.07；恢复时使用原有模块色。文章标签为 12 CSS 屏幕像素，模块为 13，字重 400、透明底，悬停不改变字号；远景保留渐隐，当前强调标签仍可读。这些数值是本轮实现选择，不宣称与 Obsidian 精确相同。
- 拖动优先于悬停，松手依据实际 DOM 命中恢复悬停；触摸结束清除强调。指针取消、失焦、隐藏、卸载与视图重建均处理清理。键盘聚焦可接管已有鼠标强调，触屏点按只打开详情。
- 邻接表按关联数据建立一次，临时强调仅改变 React Flow 外层节点的类名。位置帧仍复用节点内容数据、连线数组及手势回调，不改变布局、弹力、节点大小、缩放范围或 URL 范围恢复。色彩与透明度复用 160 ms 状态过渡，键盘立即反馈，物理 transform 不增加 CSS 过渡。
- 浏览器中另复现圆点正中心无法拖动：透明 Handle 命中后带有 `nodrag`，其默认 `isConnectable=true` 生成的 `.connectionindicator` 又启用指针事件；只设置画布 `nodesConnectable=false` 不会关闭自定义 Handle 的该选项。按组件原生 API 为 Handle 显式设置 `isConnectable=false`，保留连线锚点。相同坐标从命中透明端口变为命中圆点，中心拖动及邻居牵引恢复；未修改依赖库。

### 验证

- `pnpm test:graph`：17 项通过。沿用布局、邻域、尺寸、URL、牵引及余动测试，组件测试增加悬停／离开、直接边与邻居间边的区分、点击不固定强调、拖动锁定与内外松手、触摸结束、键盘接管、取消／失焦／后台、监听解绑、概览／详情与切换范围、字号及禁用连接端口。
- 60 次位置更新仍保持节点内容数据、连线数组与手势回调引用不变；点击详情保留拖动坐标。它是引用变化检查，不代表 FPS 量测。
- `pnpm typecheck` 与 `/StarryManual` 静态构建通过；静态链接检查继续覆盖 40 个 HTML、32 篇文章和 3379 处本地资源／链接。
- 实际浏览器以 1280 × 720 CSS 像素视口检查默认概览、悬停淡化、点击后移开恢复且保留详情、圆点中心拖动与邻居牵引、Tab 聚焦与离开、详情进入模块／局部图，以及直接滚轮缩放。局部图保留跨模块一跳邻居与独立中心标记，初始不产生常驻强调；972 × 742 视口下复查了主模块图、32 篇文章的总览与远景悬停显示标题。已留存空闲与强调状态的视口截图，验证后恢复默认视口。

### 验证边界

组件测试隔离 React 调度与 DOM 命中，实际鼠标、键盘和绘制另由浏览器复查；触摸仅做事件层验证，未用真实触屏设备验收。未进行大规模图谱、长期运行或不同浏览器／GPU 的帧率量测。构建保留前述两条 Fumadocs CSS 优化器警告与 Node 模块类型提示；本轮只本地修改与验证，不推送或发布。

## 2026-10-26：仅圆点交互、文字随图缩放与名称统一

用户进一步明确：文字不应作为节点选中区域，交互只落在圆点；文字也应随画布缩放，并将功能对外改名为“关系图谱”。此决定覆盖上一节的文字按钮与固定屏幕字号。

### 实现

- 完整图的标题按钮改为纯显示标签，React Flow 外层节点与文字均不参与指针命中，只在圆点开启命中；拖动使用组件原生 `dragHandle` 限定到 `.node-point`。圆形命中区覆盖实际圆点，并保留远景最小 32 CSS 像素的操作直径；文字排在该区域下方，透明矩形和圆形外接框的四角都穿透到画布。
- 标签取消字号、宽度与内边距的反向缩放补偿。100% 时文章 12 px、模块 13 px，标题、文档数及文字排版直接随画布缩放；圆点既有的视觉补偿与远景文字渐隐保留。
- 节点容器继续负责布局测量和键盘操作，完整图使用按钮语义与节点名称；Enter／空格打开详情，原生方向键操作继续由 React Flow 处理，标签本身不新增焦点。
- 导航、首页入口、图谱页 metadata 与英文副标题、加载和无障碍提示、404 提示、手册导览及 README 统一为“关系图谱”。现有 `/graph` 网址及范围参数继续使用。

### 验证

- `pnpm test:graph`：18 项通过，补充纯显示标签、圆点拖动入口、节点指针穿透、不反向补偿字号，以及键盘打开详情和不拦截原生方向键的检查；类型检查、静态构建与本地链接检查通过。
- 实际浏览器命中检查：圆点中心命中圆点，文字、外层留白与圆形外接框角落均命中画布。点文字不强调节点或打开节点详情；从文字区域拖动只平移画布，节点坐标不变；从圆点拖动仍牵引节点和邻居。
- 实际缩放从约 63.85% 增至 91.94% 时，同一模块标签的屏幕宽度从约 49.07 px 增至 70.66 px，和画布同比放大 1.44 倍；不把 CSS 声明字号不变误当成屏幕字号不变。Tab 聚焦及 Enter／空格打开详情另由浏览器复查。
- 重新构建后，实际浏览器页签、主导航和画布无障碍名称均为“关系图谱”；站点源码、首页入口与导览正文中未留旧的对外名称。保留更新后的本地预览与视口截图。

触摸仍只做事件层检查，未用真实触屏设备验收；不重复进行无关页面或大规模性能回归。仅本地提交，不推送或发布。
