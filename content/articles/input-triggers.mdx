## 两者各管什么

- **修饰器（Modifier）**：改变输入值，例如死区、灵敏度、反转。
- **触发器（Trigger）**：决定动作什么时候成立，例如长按、双击。

Handler 收到的是 Enhanced Input 处理过的值与事件，不要在 Handler 里再复制一套设备规则。

**作用范围**

- **按键条目上的修饰器**：只影响这一条映射。
- **Action 自身的修饰器与触发器**：作用于整个动作。

这个区别在调试时很重要：StellaDebug 的 Actions 模拟从动作层注入，不经过按键条目上的修饰器。

## 读取玩家设置的修饰器

| 类型                                     | 作用                                   |
| ---------------------------------------- | -------------------------------------- |
| `UStarrySettingBasedScalar`              | 从玩家设置中读取一个数值，按轴缩放输入 |
| `UStarryInputModifierDeadZone`           | 按玩家设置处理摇杆死区                 |
| `UStarryInputModifierGamepadSensitivity` | 应用手柄灵敏度设置                     |
| `UStarryInputModifierAimInversion`       | 应用瞄准方向反转                       |

这些偏好由玩家设置层持有，修饰器在运行时读取。不要在 Handler 里再缓存一份。改某个轴的倍率前，先确认它是否已经在按键映射或 Action 上缩放过，避免重复放大。

## 双击（Double Tap）

`UStarryInputTriggerDoubleTap` 在编辑器里显示为 **Double Tap**。一次有效的双击需要三步：

1. 第一次按下；
2. 在 `TapReleaseTimeThreshold`（默认 0.2 秒）内松开；
3. 松开后在 `TapIntervalThreshold`（默认 0.5 秒）内第二次按下。

第二次按下时触发一次，之后继续按住不会被连续算成新的双击。只长按一次也不满足规则。

- **时间膨胀**：`bAffectedByTimeDilation` 只决定按住时长是否受全局时间膨胀影响；两次按下的间隔始终按传入的 DeltaTime 累计。
- **跨重建延续**：触发器在空闲时也持续计时。映射被重建时，通过 `ReceiveTriggerReinstanced` 延续按住时长与双击进度。

测试时除了“两次快速点击”，还要覆盖两种情况：第一次松开后等太久，以及按住期间映射被重建。

工程资产中目前还没有 Input Action 使用 Double Tap。

## Handler 该响应哪个事件

Handler 要在“双击已经成立”之后执行，就响应 **Triggered**。Started 表示开始评估，不代表双击成功；Ongoing 也不能代替成功事件。

动作没有反应时，先在 [Actions 面板](/read/input-troubleshooting#手柄与动作模拟)确认 Action 最终的状态，再检查 Handler 登记的事件。玩家设置与改键见[改键与玩家设置](/read/input-settings)。

代码位置：`Framework/Input/Modifiers`、`Framework/Input/Triggers/StarryInputTriggerDoubleTap`。
