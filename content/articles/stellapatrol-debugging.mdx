StellaPatrol 没有专门的运行时面板，排查主要依靠编辑器中的区域显示、组件状态和 AI 的实际移动。这一篇先介绍编辑器显示，再按现象给出检查顺序。

## 编辑器里的显示

- **采样点**：每个采样点显示一个定位标记，颜色取区域的 `Debug Color`。
- **连接**：正向连接显示为一串方向箭头，从本区域离对方最近的位置指向对方。默认沿导航路径排列，没有导航时退回直线；箭头每隔 100 cm 一个，只在整条路径的两端给标记留出空间。
- **Shape 的边界**：闭合样条按普通样条显示，可以直接拖动样条点调整形状。

区域的 **Debugging** 分类：

| 设置                      | 作用                                           |
| ------------------------- | ---------------------------------------------- |
| `Debug Color`             | 区域及其连接的显示颜色，用来区分不同路线       |
| `Debug Mesh Scale`        | 标记与箭头的缩放，箭头间距和两端的留白随之变化 |
| `Draw Debug Mesh In Game` | 在 PIE 中也显示标记与箭头                      |

这些显示组件只在编辑器中创建，打包后的游戏里没有。项目设置中的 **StellaPatrol** 页还可以更换标记与箭头使用的网格（`Debug Point Mesh`、`Debug Link Mesh`），以及关闭沿导航路径排列箭头（`Use Nav Path`），修改后需要重启编辑器。

## 按现象排查

| 现象                                      | 检查顺序                                                                                                                                                       |
| ----------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| AI 完全不动                               | 巡逻是否已开启：`Activate At Start`、`Toggle Patrol Movement` 或行为树任务；是否在单机或服务器上运行；Pawn 是否由 AIController 控制；`First Zone` 是否有采样点 |
| 一开始就停下，`Is Patrol Active` 为 false | 第一次移动是否失败：目标点能否投影到导航、能否找到完整路径；`First Zone` 为空时附近是否有满足 `Search Params` 的区域                                           |
| 走到一半停住，之后不再巡逻                | 是否有其他系统提交了新的移动，例如行为树的 Move To；路径是否被阻断而中止                                                                                       |
| 到点后一直站着不走                        | 区域的到点动作是否调用了 `Finish Zone Action`                                                                                                                  |
| 一直在一个区域里打转                      | `Next Zone Wait Time` 是否过长；后继区域的 `Weight` 是否为 0、是否有采样点；当前区域是否根本没有连接，且附近没有其他符合条件的区域                             |
| 走到末端没有折返                          | 末端区域是否真的没有正向连接；`Previous Patrol Zone` 是否列出了来路                                                                                            |
| 去了路线以外的区域                        | 当前区域没有可用连接时，会从所有已登记的区域中挑选；检查连接与目标区域的权重、采样点                                                                           |
| 行为树任务立刻失败                        | Pawn 上是否有巡逻组件；巡逻是否已经开启（例如勾选了 `Activate At Start`）                                                                                      |
| 客户端调用开启没有反应                    | 开启、停止与切换区域只在权威端执行，在服务器上调用                                                                                                             |

## 自动化测试

插件的编辑器模块带有三组自动化测试，可以在 Session Frontend 中按 `StellaPatrol.` 筛选运行：

| 测试                                    | 覆盖                                                                         |
| --------------------------------------- | ---------------------------------------------------------------------------- |
| `StellaPatrol.GeometryAndQueries`       | 区域几何、移动区域后的查询、空采样、半径边界、折返与零权重                   |
| `StellaPatrol.MovementAndActionCleanup` | 实际路径跟随、主动取消、外部新请求、动作实例隔离、定时器与控制器失效时的清理 |
| `StellaPatrol.Editor.LinkSpacing`       | 编辑器连接箭头的跨段等距、重复点、短连接、箭头方向与显示缩放                 |

移动测试使用关闭寻路的测试控制器，沿直线路径跟随，不覆盖导航网格上的绕障、多人联机、按固定曲线行进和大规模性能。

代码位置：插件 `Plugins/AI/StellaPatrol`，显示设置 `Source/StellaPatrol/Public/StellaPatrolEditorSettings.h`，区域显示在 `StellaPatrolZone` 的编辑器部分，测试在 `Source/StellaPatrolEditor/Private/Tests`，标记源文件在 `Resources/MapMarkers`。
