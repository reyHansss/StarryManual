移动平台的导航不在世界网格里，而是在编辑器中按平台自己的坐标系烘焙成局部导航资产，运行时由导航表面登记为一个独立的导航实例。平台怎样运动由平台自己负责，导航只跟随它的位姿。这一篇说明怎样配置、烘焙和编辑平台导航。

## 配置导航表面

在平台 Actor 上添加 **Stella Navigation Surface**，在 **Navigation** 分类中配置：

| 设置                  | 含义                                                                                                         |
| --------------------- | ------------------------------------------------------------------------------------------------------------ |
| `Base Component`      | 平台的参考系基座，同时是默认的碰撞来源。可以是蓝图中的非根子组件，也可以带固定缩放，缩放会被吸收到烘焙几何中 |
| `Additional Geometry` | 与基座一起运动、需要合并烘焙的其他碰撞，例如固定的楼梯、栏杆；必须属于同一个 Actor，并且相对基座固定         |
| `Base Bone`           | 可选，使用基座上的某个骨骼或 Socket 作为参考系                                                               |
| `Mesh Assets`         | 局部导航资产，每种代理一份；运行时按代理的半径与高度匹配，容差 0.1 cm                                        |

- **只认明确配置的碰撞**：默认只烘焙 `Base Component` 的碰撞，不会顺着附着关系收集子组件。可见网格的 LOD 不参与，烘焙使用碰撞。
- **一个碰撞只能属于一个表面**：同一个碰撞组件出现在两个表面里，或引用了别的 Actor 的组件，烘焙和登记都会失败并给出原因。
- **平台不要参与地面导航**：平台的碰撞组件关闭 `Can Ever Affect Navigation`，只保留碰撞，否则平台会在初始位置被一起烘焙进地面导航。

## 烘焙局部导航

选中一个或多个带导航表面的平台，在视口中右键，选择 **导航 → StellaNavigation → 烘焙所选平台的局部导航**。所选 Actor 中只要有一个没有导航表面，菜单就是灰的。

- **读取当前代理**：工具从关卡中每种代理的实际导航数据读取半径、高度、步高、坡度、体素尺寸以及自动遍历分析的配置，为每种代理生成一份资产。
- **资产放在哪里**：缺少匹配资产时先弹出文件夹选择框，新资产命名为 `ANM_<Actor 名>_<代理名>`；已有匹配资产时原地更新。取消选择不会修改任何资产。
- **全部成功才替换**：烘焙成功后重新登记导航表面；失败时保留旧的资产与已登记的导航。
- **共用资产**：尺寸、原点、碰撞和代理规格都相同的平台可以共用一份资产，重新烘焙会更新所有使用它的平台。几何不同的平台要用不同的资产。

平台的碰撞、缩放或附属组件改变后，要从关卡里重新右键烘焙，让工具重新采集碰撞；只修改生成参数时，也可以在资产编辑器中重新烘焙。

## 一个 Actor 里的多个运动部件

导航实例按独立运动的刚体划分，而不是按 Actor 划分：

- **相对船体固定的部分**：船体和固定在它上面的楼梯、栏杆共用一个表面，楼梯、栏杆放进 `Additional Geometry`。
- **会自己运动的部分**：甲板上的升降台、转台各自配置一个表面，`Base Component` 指向各自的碰撞网格。

例如船体下附着固定楼梯和一个升降台：`HullSurface` 的基座选船体，`Additional Geometry` 加入楼梯；`LiftSurface` 的基座选升降台，`Additional Geometry` 加入升降台上的护栏。两份列表互不重叠，分别烘焙。升降台即使附着在船体下，没有自己的表面也不会进入船体的导航。

右键烘焙会更新所选 Actor 的全部表面和全部代理变体。这些部件可以在同一个 Actor 里，也可以拆成多个 Actor，按生成、销毁和联机管理的需要决定。当前不支持蒙皮变形，也不支持一个组件内多个各自运动的骨骼。

## 平台运动时

- **平移与旋转**：不需要重新烘焙。导航表面在每帧物理更新后采样平台的位姿与速度，已有路径随平台移动。
- **瞬移**：调用导航表面的 `Notify Teleported`，避免把一次瞬移当成高速运动，并让相关路径重新检查。
- **缩放**：运行中改变基座的缩放会使通行空间失效，表面会注销，需要重新烘焙。
- **动态创建**：运行时添加导航表面时，先设置 `Base Component`、`Additional Geometry` 和 `Mesh Assets`，再注册组件。导航数据先登记还是后登记都没有关系。
- **速度不要重复叠加**：角色站在平台上时，Mover 按脚下实际的支撑组件处理平台运动，表面采样的速度已经包含父级的运动，业务不要再叠加一次平台速度。

## 资产编辑器

双击局部导航资产打开专用编辑器：

- **预览**：灰线是碰撞来源，绿面是保存的可走面；自定义区域的可走面使用该区域类的绘制颜色。自动生成的连接显示为黄色，手工连接为青色，区域修饰盒为橙色，自动分析源范围为紫色。
- **只读记录**：左侧的 `Build Settings` 与遍历分析配置，是上次成功烘焙时采用的参数。

### 手工配置

顶部的三个按钮分别添加手工连接、区域修饰盒和自动分析源范围，也可以直接在细节面板的 **Authoring** 分类中增删数组。全部坐标和尺寸都是资产局部的厘米。

| 配置               | 内容                                                                                                                                                                          |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Manual Modifiers` | 局部旋转盒与 `Area Class`；填写 `Replace Area Class` 时只替换指定的原区域；区域选 `NavArea_Null` 表示裁掉这块；按数组顺序应用在场景导出的修饰体之后                           |
| `Manual Links`     | 资产内部的手工连接：`Start`、`End` 两条端线，沿局部 Z 的 `Projection Half Height`（默认 35 cm），方向，单一 `Area Class`（默认 `NavArea_Default`），可选的 `Link Proxy Class` |
| `Analysis Ranges`  | 限制资产内部自动分析的源范围，见[自动遍历通道](/read/stellanavigation-traversal#限定自动通道的范围)                                                                           |

手工连接的端线要长于 5 cm，并且不能平行于局部 Z。连接的基础费用由两条端线中点的距离决定；穿越费用、固定进入费和排除规则通过 NavArea 与查询过滤器设置。需要在入口执行自定义动作时，在 `Link Proxy Class` 中选择共享的执行代理类，见[导航连接](/read/stellanavigation-links#共享执行代理)。

**视口编辑**：点击青色连接的端点或端线中心、橙色或紫色盒的中心，再用 `Q／W／E／R` 切换选择、移动、旋转、缩放。端点只能移动；端线中心可以移动、旋转和缩放该端的两个端点；盒中心的缩放调整盒的大小。按 `Delete` 删除所选的整条配置，支持撤销与重做。

### 重新烘焙

在编辑器中选择 **当前关卡导航代理**，再点击 **按所选导航配置重新烘焙**：使用资产保存的碰撞几何、手工配置和所选代理的当前参数生成，全部成功后才替换结果。关卡中只有一种代理时自动选中。

- **手工配置在烘焙后才生效**：拖动手柄只改变创作输入，运行结果要重新烘焙才更新。
- **调整生成参数**：先修改关卡中对应代理的导航数据，再重新烘焙；资产里记录的旧参数不能单独用来生成。
- **碰撞变了要回到关卡**：资产编辑器使用保存的碰撞几何；平台碰撞改变后，从关卡右键重新烘焙。

## 平台上的区域

烘焙时，范围内的 NavModifier 等导航修饰体会和资产的 `Manual Modifiers` 一起导出，区域随平台一起运动。区域类必须已经登记到导航数据中。运行时还可以用动态障碍改变平台上的区域，见[动态障碍与避让](/read/stellanavigation-obstacles)。

代码位置（插件 `Plugins/AI/StellaNavigation/Source`）：`StellaNavigation/Public/Sections/StellaNavigationSurfaceComponent.h`（导航表面）、`StellaNavigation/Public/Mesh/StellaNavigationMeshAsset.h` 与 `StellaNavigationMeshAuthoring.h`（局部导航资产与手工配置）、`StellaNavigationEditor/Private/StellaNavigationEditorTools.cpp`（右键烘焙）、`StellaNavigationEditor/Private/StellaNavigationMeshAssetEditor.cpp`（资产编辑器）。
