## 从可复用规则开始

假设有一份“轻攻击”配置，定义动作名称、缓冲时间和可触发的时机。不同角色可以引用这份配置，无需为每个角色复制一份相同参数。

配置表达规则；当前是否正在攻击、输入还剩多少有效时间，属于使用者的运行状态。

## 先确认改动范围

共享配置修改后，所有使用它的对象都可能受到影响。修改前先确认使用场景；只有少数使用者需要不同规则时，再建立语义明确的独立配置。

| 内容         | 适合放在哪里 | 原因           |
| ------------ | ------------ | -------------- |
| 缓冲有效期   | 共享配置     | 描述规则       |
| 当前输入时间 | 独立状态     | 每次输入都不同 |
| 当前执行者   | 调用上下文   | 随使用者变化   |

## 用实验理解参数

在[输入缓冲](/read/input-buffer)中，同一条规则可以产生不同结果。缓冲时间相同，按键时刻不同；按键时刻相同，缓冲时间也可以不同。

当配置需要参与运行时，继续阅读[运行与生命周期](/read/runtime)。如果还没有全局视角，可以先回到[架构导览](/read/architecture)。
