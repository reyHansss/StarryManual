这一篇搭一套最小配置：NPC 只有一个行为“Idle”，执行内容是等待 1 秒，结束后重新选择。它不移动也不播动画，目的是确认 StellaUtilityAI 的整条链路已经接通。

下面的 `AIBM_Example` 等名称是示例，需要你自己创建；项目里不一定有这些资产。

## 第一步：行为配置

1. 在内容浏览器右键 → **AI → StellaUtilityAI → Behavior Modifier (AIBM)**，命名为 `AIBM_Example`。
2. 双击打开。它是一个蓝图资产，编辑器会自动打开 **Behavior Modifier** 页签。
3. 在 `Normal` 下添加一个 Behavior，路径填 `Idle`：
   - Behavior 类型用基础 Behavior；
   - `ObjectiveClass` 留空，表示不需要任何机会；
   - `StaticWeight` 保持默认的 0 即可。只有一个候选时，分数高低不影响结果。
4. 在这个 Behavior 的 `Logic` 中选择原生的 Wait，设置 `Seconds = 1`。
5. 编译并保存。

## 第二步：Stack 与 Objective 配置

1. 右键 → **AI → StellaUtilityAI → AIBehaviorModifierStack (AIBMS)**，命名为 `AIBMS_Example`，把 `AIBM_Example` 加入列表。打开 Stack 编辑器时，右侧的最终组合预览里应该能看到 `Idle`。
2. 右键 → **AI → StellaUtilityAI → AIObjectiveComponentSetup (AIOCS)**，命名为 `AIOCS_Example`。这次的 Wait 不依赖任何机会，`GeneratorTemplates` 可以留空。

## 第三步：角色配置

1. 右键 → **Starry → AI → Starry AI Setup**，创建 `UStarryAISetupDataAsset`，并填写：
   - `BrainType = Composition`；
   - `ModifierStack = AIBMS_Example`；
   - `ObjectiveSetup = AIOCS_Example`；
   - `PerceptionSenseProfile`：可以复用已有的 Sense Profile。新建时配置需要的感官，并让 `DominantSense` 与其中一种感官一致。
2. 把 AISetup 保存在 `/Game` 下。Asset Manager 只扫描这个范围内的 `StarryAISetupData`。
3. 选一个 `AStarryAICharacter` 的派生蓝图，在 `AISetup` 中填入刚才的资产。它的默认 Controller 已经是 `AStarryAIController`，不需要改。
4. 把角色放进关卡。关卡中直接放置的角色会被自动控制；如果角色在运行时生成，把 `Auto Possess AI` 设为 `Placed in World or Spawned`。

<Note title="资产校验会拦住的配置">

Composition 模式要求 `ModifierStack`、`ObjectiveSetup` 和 `PerceptionSenseProfile` 都已填写。即使这次的 Wait 不使用感知，也要填感知配置；`PerceptionAwarenessProfile` 是可选的。

</Note>

## 第四步：运行并确认

1. 在单机或服务器模式下运行 PIE。客户端世界不运行 AI 决策。
2. 按 F1 打开调试输入，在 **AI → Agents** 中选中这个 NPC。
3. 打开 **AI → StellaBehavior**，应该能看到：
   - 行为树里只有 `Idle`；
   - 它周期性地变为当前执行（黄色），每次执行约 1 秒；
   - 下方的 Timeline 记录每一次开始和结束。

`CooldownSeconds` 默认是 0，所以 Idle 结束后可以立刻再次被选中。想看清两次执行之间的间隔，可以给这个 Behavior 设置冷却。冷却属于 Behavior，不是 Wait 的参数。

## 没有按预期运行时

| 现象                      | 先检查                                                                           |
| ------------------------- | -------------------------------------------------------------------------------- |
| Agents 列表里没有这个 NPC | 角色是否被 `AStarryAIController` 控制；AISetup 的 `BrainType` 是否为 Composition |
| Controller 停在初始化阶段 | AISetup 是否通过资产校验；是否放在 `/Game` 下；是否收到了 `OnAISetupFailed`      |
| 行为树里看不到 `Idle`     | Stack 是否引用了正确的 AIBM 类；AIBM 是否已编译保存                              |
| `Idle` 存在但从不执行     | Logic 是否已设置；冷却是否过长                                                   |

更完整的排查路线见[调试与排查](/read/stellautilityai-debugging)。
