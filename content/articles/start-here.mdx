## Starry 是什么

Starry 是一个 Unreal Engine 5.8 游戏项目，运行在自维护的源码引擎 StarryUE 上。玩法与框架以 C++ 为主：

- **玩法装配**：由 Experience 描述一局游戏要装配哪些内容；
- **角色**：使用 Mover 移动；
- **技能与战斗**：建立在 GAS 之上；
- **AI**：由项目的 StellaUtilityAI 决策、StellaNavigation 导航；
- **生态**：由生态系统模拟大量生物的需求、日程与资源。

## 游戏方向

以下方向已经确定，它们约束着框架设计，其中大部分联机能力还没有实现：

- **探索与存档**：探索可以离线进行，非付费内容与进度走本地存档。
- **网络部署**：按玩法选择部署方式。PvP 这类玩法可以由服务器权威执行；本地存档不等于客户端拥有战斗权威。
- **公共大厅**：可以看到大量陌生玩家。
- **合作探索**：朋友进入同一环境后可以连续自由探索，承接任务时可以有过渡。

## 现在有什么

| 范围      | 已有能力                                                                                    |
| --------- | ------------------------------------------------------------------------------------------- |
| 框架      | 四类角色（玩家、AI、NPC、怪物）、移动、能力与战斗、输入、装备、背包、阵营、相机、设置与界面 |
| 玩法      | 生态运行框架、怪物状态、任务、前端流程                                                      |
| AI 与导航 | StellaUtilityAI 组合决策及 BT／StateTree／HTN 后端、StellaNavigation、StellaPatrol          |
| 工具      | StellaDebug 调试面板与远程查看、模块化编译工具 Starry UE Build                              |

目前**还没有**正式关卡（`Content/Maps` 为空），游戏流程尚未定稿，玩家进度的本地存档也还没有实现。

## 这本手册怎样用

- **找内容**：左侧用模块菜单切换系统，按 `Ctrl K` 全文搜索标题、术语、概念和 API 名称。
- **查术语**：每个模块在自己的文章里定义术语，文章末尾列出“本页术语”；页眉的“术语”汇总全部术语，可以按模块浏览和筛选。
- **看图**：正文图表可以滚轮缩放、拖动和全屏查看；部分时序图可以“逐步播放”。
- **交互演示**：带“交互演示”标签的卡片可以直接操作，计算规则与项目源码一致。
- **关系图谱**：根据文章之间的链接生成，表示“可以一起读”，不表示代码依赖。

目前已经写成专题的模块有游戏框架、StellaUtilityAI、StellaDebug、Input、Async Message 与 AsyncMixin，其余系统会陆续补齐。
