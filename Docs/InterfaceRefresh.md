# 界面分区、动效与功能改版记录

## 2026-10-27：整体优化阅读界面

用户反馈手册网页审美不足，要求查看后修改界面分区、界面动效与界面功能等。本轮只调整共享主题与组件，不改文章内容；沿用 AGENTS.md 已确定的接近白色的底色、暖粉主色、蓝色链接、圆润控件、桌面正文 17 px／行高 1.95、首页双栏与粒子肖像、推荐站点位置，以及 `app/motion.css` 的时长约定。

### 改版前核对到的问题

以 2560×1290、1920×950、1440×760 与 390×780 视口截图核对：

- 强调色 `#ad5360` 的 HSL 饱和度约 35%，按钮使用硬质下沉阴影，整体偏灰暗；大量说明文字为 10–11 px。
- 页眉高 84 px；阅读页侧栏边框只延伸到目录末尾，看起来断在半截；正文最宽 1000 px，约 58 个汉字一行。
- 右栏目录不标当前位置；导览页的关联列表平铺 16 条；页头的 `STARRY / MANUAL` 字样与模块胶囊重复面包屑信息。
- 全站搜索只能用鼠标点选，结果按目录顺序而不是命中程度排列，没有命中标记和正文片段；搜索文本混入蓝图节点与图表源码。
- 1920×950 下图谱画布底部、缩放控件与详情说明被裁到屏幕外。

### 分区

- 页眉 64 px：品牌、分隔线后左对齐的两个主入口、加宽的搜索框、编辑入口与动效开关；手机拆成两行，主入口占满第二行。
- 阅读页左栏占满视口高度：顶部模块菜单显示模块色点、全称与篇数，目录独立滚动，底部固定“回到首页”和“模块关系图谱”。栏间分隔线由布局绘制并贯穿正文；侧栏预留页脚高度，滚到文末时不会被页脚顶到页眉下方。
- 正文行宽限制为 800 px，2200 px 以上视口为 860 px；图表、蓝图、代码块与表格可放宽到 1080 px（超宽屏 1200 px）。二级标题以细线分节，紧接页头的首个小节不重复分隔。
- 页头保留面包屑、标题与简介，下方为模块色标签和编辑入口。
- 右栏为本页目录与关联阅读卡片；“从这里出发”和“链接到本页”各显示前 6 篇，其余折叠，底部为“本页关系图谱”。1100 px 以下右栏收起，标题下提供折叠目录。
- 模块入口的功能卡片顶部使用模块色细条，标题使用模块文字色；颜色仍来自 `lib/navigation.ts` 的模块定义。
- 图谱页画布与详情区按可用高度伸缩，1920×950 和 1440×760 下一屏可见画布、缩放控件、图例和详情说明；手机仍为 400 px 画布，详情在下方。

### 配色与排版

- 强调色改为 `#c2405c`（饱和度约 52%），悬停 `#a5334d`；新增 `--accent-bright`、`--accent-tint` 只用于装饰、描边与选中底色。链接蓝改为 `#2d6994`。用作文字的颜色在对应底色上的对比度：强调色 5.02、选中项 5.91、链接 5.90、说明文字 4.67–4.90、正文 10.44。
- 阴影改为暖色低透明度叠层；按钮改为胶囊形与柔和投影。标题字重统一为 700–750，避免 800 落到 Segoe UI Black；常用说明文字提高到 12–14 px；行内代码去掉描边，改为浅底等宽字。
- 首页结构、粒子图片和推荐站点不变；品牌字改为墨色到暖粉的渐变，版本标签改为描边胶囊。

### 动效

- 右栏目录复用 Fumadocs 的标题观察与指示轨道，只标出一个当前小节。
- 阅读进度条与页眉阴影使用 CSS 滚动时间线，直接跟随滚动位置，没有独立播放时长；不支持滚动时间线的浏览器不显示进度条。
- 侧栏分组、窄屏目录与关联折叠以 200 ms 随内容高度展开（`interpolate-size`、`::details-content`）；减少动态效果时直接切换。
- 上一篇／下一篇卡片与推荐站点在精细指针悬停时上移 2 px，箭头随方向移动。搜索窗口即时出现，当前项与键盘移动不加过渡。

### 功能

- 搜索：多个关键词须全部命中；标题高于简介、简介高于正文，同分保持目录顺序；标题、简介和正文片段标出命中，片段从窗口内第一个句读或空格之后开始。方向键循环移动、回车打开、Esc 关闭；中文输入法组合期间不响应方向键与回车。空查询按模块分组列出全部文章，底栏显示结果数和快捷键。
- 搜索文本由 `lib/search.ts` 统一生成：代码保持原样，图表与蓝图只保留标题。阅读布局为每个页面下发的搜索数据因此不再包含节点源码。
- 目录提供“回到顶部”；“本页关系图谱”打开 `/graph?module=…&center=…` 的局部图；侧栏“模块关系图谱”打开当前模块图。

### 验证

- `pnpm format:check`、`pnpm check:content`（32 篇文章、127 个本站链接）与 `pnpm typecheck` 通过；全部 49 项单元测试通过。新增 `tests/search.test.mjs` 4 项，覆盖搜索文本提取、排序与多词、片段边界和命中切分，已加入 `test:search` 与 Pages 工作流。
- `/StarryManual` 静态构建与 `pnpm check:pages` 通过：40 个 HTML、32 篇文章、3590 处本地资源／链接。
- 在开发服务与 `/StarryManual` 静态预览中用浏览器脚本各核对 9 项交互：Ctrl+K 打开并聚焦、方向键循环与回车跳转、输入法组合期间不跳转、目录只标当前小节、阅读进度比例、回到顶部、侧栏分组展开、局部图深链、侧栏模块切换，以及窄屏折叠目录跳转。
- 视口截图核对 2560×1290、1920×950、1440×760、900×1000 与 390×780（DPR 2）下的首页、导览、模块入口、长文首尾、图谱、搜索、蓝图预览与 404。

### 边界

- 未改动关系图谱组件逻辑、粒子算法以及蓝图与图表的内部渲染，只调整外层尺寸和共享配色。
- 交互核对使用 Edge；未用真实触屏设备、Firefox 或 Safari 验收，也未做帧率测量。
- 上述色值、行宽、字号与时长是本轮实现选择，不是用户逐项指定的参数。仅本地修改与提交，未推送或发布。

## 2026-10-28：首页品牌字尾裁切修复

- 用户截图中的 `y` 下沿仍被裁掉；上一轮只增加行高没有解决渐变文字的绘制边界。为 `.hero-name` 增加 `0.16em` 底部内边距，让渐变包住完整字尾，以等量负外边距保持下一行排版位置。
- 按用户后续要求，将品牌字行高从 `1.15` 还原为 `1.08`，保留底部绘制余量与等量负外边距。
- 浏览器对照修复前后的局部截图，确认平直截断处恢复为完整弧形；在 1099 × 742 和 1920 × 1080 视口下分别检查约 84 px 与 125 px 字号。截图位于忽略目录 `.verification/hero-y-*.png`，检查后恢复原视口，本地预览继续运行。
- 仅修改首页品牌字样式并记录 Codex 共同署名要求；格式与差异检查通过，未做全站回归或静态发布构建，未推送或发布。

## 2026-10-30：增加图谱画布高度并修正高亮层级

- 用户反馈图谱上下空间不足、高亮节点和文字会被其他节点遮挡。1280 × 720 视口下，原画布高约 332 px，页头和两排工具栏挤占了可用高度。
- 页头改为“关系图谱”与同行简介，去掉重复的装饰标签和操作提示；桌面图谱路径与筛选共用一排，路径较深或窗口较窄时自然换行。画布继续填满剩余空间，同一视口下高约 433 px，增加约 31%，整页无滚动；1440 × 680 下画布约 391 px，页脚仍在视口内。390 × 780 下保留 400 px 画布和下方详情，无横向溢出。
- React Flow 的外层节点统一设置层级，当前悬停、拖动或键盘聚焦项高于直接关联项，直接关联项高于其他节点，圆点和标题一起提升。完整图关闭选中项自动提升，避免之前点选的节点覆盖当前高亮；紧凑预览沿用原选中行为。移开或取消时恢复对应层级，不新增常驻颜色强调。
- `pnpm test:graph` 的 21 项测试与 `pnpm typecheck` 通过；新增层级回归覆盖高亮、邻居、历史选中、拖动、取消恢复和紧凑预览。浏览器检查主模块与全部文章视图，确认实际 DOM 层级与键盘焦点切换，复查节点拖动以及桌面和窄屏布局；截图保存在忽略目录 `.verification/`。
- 仅本地修改与提交，未推送或发布；未做全站回归、静态构建或真实触屏验收。
