## 什么时候用

调试面板默认画在游戏视口里，会挡住画面，也占用游戏的输入。netImgui 把面板显示到一个独立的桌面程序中：

- 游戏画面保持干净，面板可以放在另一块屏幕上；
- 可以连接没有窗口的进程，例如专用服务器，查看它的面板。

netImgui 把桌面程序叫作 Server，游戏一端叫作 Client。这只是界面传输中的命名，和 UE 的游戏服务器无关。

## 构建桌面查看器

双击项目根目录的 `NetImgui/Build.bat`，或在 PowerShell 中运行：

```powershell
./NetImgui/Build.bat
```

- **找到工具链**：脚本通过 vswhere 找到 Visual Studio 2022（需要 C++ 桌面开发与 Windows SDK）和它附带的 CMake。也可以用 `-CMakePath` 指定 CMake。
- **产物**：`NetImgui/NetImguiServer/NetImguiServer.exe`，使用静态 C++ 运行库；中间文件在 `NetImgui/Intermediate`。复制给别人时保留整个输出目录。
- **参数**：`-OutputDirectory` 指定输出目录，`-Configuration Debug` 生成调试版本。

桌面程序与游戏插件使用同一份 netImgui 1.13 源码，协议一致。

**推荐的本机连接方式：**

1. 启动 `NetImguiServer.exe`。
2. 启动 PIE 或 Development 游戏，按 F1 打开调试输入。
3. 打开 **Engine → Debug Tools → Net ImGui**。
4. 服务器地址填 `127.0.0.1`，端口 `8888`，点击 Connect。
5. 在桌面程序中查看面板，确认连接的是你要排查的那个游戏实例。

也可以反过来：让游戏 Listen（默认端口 8889），再在桌面程序里添加连接。跨机器连接时填写对方机器的地址。

**自动行为**

- **自动连接**：可以按 Standalone、Client、Listen Server、Dedicated Server 分别设置，模式有 NoAutoConnect、AutoConnect、AutoListen 三种。默认只有 Dedicated Server 是 AutoConnect。
- **自动启动桌面程序**：Auto Run Server 只在 PIE 中生效，默认关闭。
- **程序位置**：桌面程序目录留空时指向项目的 `NetImgui/NetImguiServer`；打包后的游戏可以配置单独的工具目录。

## 控制台命令

| 命令                               | 作用                           |
| ---------------------------------- | ------------------------------ |
| `StellaDebug.NetImgui.Connect`     | 按窗口中保存的设置发起连接     |
| `StellaDebug.NetImgui.Listen`      | 在客户端端口上等待桌面程序连接 |
| `StellaDebug.NetImgui.Disconnect`  | 断开当前连接                   |
| `StellaDebug.NetImgui.RunServer`   | 启动配置好的桌面程序           |
| `StellaDebug.NetImgui.CloseServer` | 关闭由工具启动的桌面程序       |

## 远程显示的边界

netImgui 只传输面板界面和对面板的操作。选框、碰撞和 Gizmo 仍然在游戏视口里逐帧绘制，不会出现在桌面程序中。

- **选取与拖动**：在桌面面板点了拾取之后，要回到游戏视口左键选择、右键取消；拖动 Gizmo 时，要在游戏视口按 F1 打开调试输入后再拖。
- **断开之后**：面板恢复在本地显示。
- **不做复制**：远程显示不提供 Actor 复制或绘制 RPC。连接到客户端进程时看到的是那个客户端的状态；修改会不会影响服务器，由实际使用的领域接口决定。

## 连不上时

1. 桌面程序是否已经启动；
2. 两端是否选了匹配的方向（一端 Connect、另一端 Listen）；
3. 端口是否一致；
4. 连接的是不是要排查的那个游戏实例。

开多个实例时，给客户端起容易辨认的名字，避免在错误的进程里追查状态。

面板已经连上、游戏视口里却没有图形时，检查当前世界、窗口的绘制开关和视口调试输入。界面连接成功不代表三维内容也会显示在桌面程序里。
