# Starry手册

Starry 游戏项目的文档，面向项目使用者与开发者，按模块、子模块与具体功能组织用途、配置、技术架构、扩展与排查。项目基于 UE 5.8，文档随项目开发持续补充。

当前已整理 AstraAI、HaloDebug、项目 Input、原生 Async Message System 和 AsyncMixin；模块入口说明职责与子模块协作，具体功能在所属层级展开使用与机制。项目首页保留标题、星星向导与文档关系区域，下方为外部推荐站点；“阅读文档”进入普通手册导览，侧栏切换模块并查看当前功能树，工程分层页补充装配与依赖边界。

手册在自己的 Git 仓库管理，内容与站点资源独立。当前只在本地修改、验证和提交，不推送或发布。

## 本地运行

环境：Node.js 22.18+（推荐 24 LTS）、pnpm 11。本机使用 Node.js 24.19.0、pnpm 11.25.0。

```powershell
pnpm install
pnpm dev
```

访问 <http://127.0.0.1:3210>，右上角“编辑内容”进入本地网页编辑器，文章标题下“编辑本页”直接打开当前文章。开发服务绑定回环地址。

```powershell
pnpm format:check
pnpm check:content
pnpm build:pages --base-path /StarryManual
pnpm check:pages
pnpm preview:pages --port 3211
```

静态预览：<http://127.0.0.1:3211/StarryManual/>。本机预览中的编辑入口跳转到 `3210`，需要同时运行 `pnpm dev`；线上静态站不显示本机编辑入口。`out/` 是忽略的构建产物，不提交。静态预览使用已构建内容，修改后需要重新构建；开发模式直接重新编译。

## 修改内容

文章位于 `content/articles/*.mdx`，本地文件和 Keystatic 网页编辑修改同一份内容。元信息包含标题、简介、所属层级与阅读顺序。文章沿用所属模块的稳定前缀；新模块在 `lib/navigation.ts` 登记一次，目录、图谱与搜索共用模块定义和颜色，未单独归组的文章进入项目系统，空分组不显示。

项目首页保留独立版式、黄色星星向导和原文档关系区域，移除全量模块卡片与重复阅读路径；文档关系区域暂时沿用现有展示，后续用途尚未确定。阅读入口恢复为普通 `content/articles/start-here.mdx` 导览文章，使用与其他文章相同的版式，不额外生成欢迎页或全站功能总览。侧栏提供模块搜索和当前模块目录；页眉搜索与 `Ctrl K` 共用一个窗口，图谱用于探索阅读关联。

首页推荐站点的数据位于 `content/site-links.json`，也可在 Keystatic 的“首页推荐站点”中编辑名称、简介、网址和顺序。首个站点为用户提供的 UE-Book；卡片复用共享排版，在新标签页打开外链，不引入远程图片或第三方脚本，新增链接无需改页面代码。

`section` 数组从外到内表示子模块或功能分区，例如 `section: [行为执行, 树后端]`；模块总览留空。侧栏通过可搜索、可滚动的模块菜单切换，只显示当前模块的多层目录；模块总览保留自身的功能目录，当前位置可回到所属模块及功能区。上一页与下一页按模块内目录继续，不跳到其他模块。手机使用可展开的同一目录树与模块菜单。

不再把文章强制分为使用指南、技术架构或节点与参考，MDX 和网页编辑器已移除该字段。功能需要时在同页解释操作、机制与排查，复杂子模块再拆页；参数或命令需要速查时再设置相应小节。日常笔记只维护正文与所属层级，不再编辑目录清单、图谱分类或页面代码。

正文 `/read/slug` 链接自动生成出链、反链和图谱。图谱默认展示主模块，可切换全部文章；模块节点汇总文章数量，连线汇总已有跨模块阅读链接。模块入口使用与阅读侧栏共用的可搜索、可滚动菜单；功能分区按目录树逐级展开，支持悬停、点击与键盘，图谱控件按当前选中名称自适应宽度。窄屏在同一菜单面板逐级进入并提供返回入口。模块、功能路径、中心节点、搜索与显示层级使用 `module`、`section`、`center`、`q`、`display` 参数恢复。局部图包含中心文章与正反向一跳邻居，保留跨模块关系，返回时恢复原模块、功能范围和全局显示层级。

笔记以任务、配置步骤、原理、约束和排查为结构。只总结已有实现、实际用法和用户提供资料，不私自添加功能、架构方案或示例组件。接口、字段、默认值与单位核对实际实现；图示中的占位名称明确说明，不假装是项目已有类型或已提供资产。

## 图表与视觉约定

正文用共享 `Diagram` 输入 Mermaid 关系、流程、时序或状态。自动布局、四色主题、滚轮缩放、左键平移、键盘操作与全屏由共享组件提供，日常不手调坐标或单篇样式。

知识图谱展示阅读关联，不表示模块依赖；程序调用与对象关系由正文图表明确表达。完整图谱拖动关联节点会产生有限的弹性牵引，静止和不可见时停止计算，减少动态效果时关闭余动。缩小时文章标签随缩放渐隐，远景只保留节点与连线，放大后恢复。

完整图的圆点面积随当前可见连接数增长，悬停圆点可查看连接数；大枢纽设置尺寸上限。缩放范围为 8%–400%，圆点屏幕直径随 `zoom^0.55` 变化，位置与连线仍使用真实缩放。标签与操作按钮保持屏幕可读尺寸，圆点的视觉补偿不改变布局或连线中心。

用户已确认当前明亮、圆润、偏二次元的阅读设计。继续使用中性白底、暖粉主导、蓝色链接、清透图表和黄色星星向导；正文稳定、深灰文字、限制行宽，电脑利用导航与关联栏填满空间。

浏览器页签图标沿用页眉品牌星标的蓝粉渐变与星形，使用浅白粉圆角底；首页黄色星星向导继续保留自身形象。

设计参考包括 [Emil Kowalski skills](https://github.com/emilkowalski/skills) 的动效节奏和 [garden-skills](https://github.com/ConardLi/garden-skills) 的共享 token、语义组件与可读性思路。参考研究不等于安装技能或引入运行依赖。重要约束保存在本仓库 `AGENTS.md`。

## 正文蓝图说明

介绍蓝图用法时，在文章中使用 `BlueprintViewer`，填写 `title` 与 `source`；网页编辑器提供同名含义的标题和多行节点文本字段。节点文本随文章保存与静态发布，打开正文直接渲染，支持多图、左键平移、滚轮缩放、触屏手势与原始文本查看。单组最多 200,000 字符。

画布根据实际节点边界自动取景，初次尽量展示整组节点且不把小图额外放大；提供“适应画布”和“100%”切换，重置恢复取景。取景沿用 20% 的缩放下限，极大图可以平移阅读。日常笔记不单独填写画布尺寸、坐标或初始缩放。

`/blueprint` 仅用于写作时临时粘贴检查，文本刷新后移除，不列入主导航。共享画布只加载本地 blueprintUE 渲染器与手势脚本。

查看器不执行蓝图、不读 `.uasset`。复杂自定义节点、动画、材质、Niagara 与 PCG 的兼容性需按目标文本验证，不能把渲染器存在视作全部图种已验证。
